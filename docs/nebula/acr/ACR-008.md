An operator can select an ADE Source, invoke Generate with AI on Create, receive a persisted `live_ai` draft, edit it, and approve or reject it in Review. Unapproved AI drafts cannot enter the publishing queue. Mock/manual drafts still work. Intelligence/analytics remain deterministic.

Live path proven against OpenAI `gpt-4o-mini` on localhost. Failed generate (missing source / unknown source) did not create a draft. Missing-credentials detection unit-tested.
