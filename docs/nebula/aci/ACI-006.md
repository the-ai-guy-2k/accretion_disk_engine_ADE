# ACI-006 — ADE Campaign Planning & Content Automation
**Product:** Accretion Disk Engine (ADE)
**QEN:** Social Engine Build QEN
**Execution:** AIA / CAE — Local
**Type:** MVP Automation Vertical Slice
**Implementation Changes:** AUTHORIZED
## Current Truth
ADE has established the core operating loops:
**Source → Draft → Review → Approval → Queue → Publishing**
and:
**Goal → Content → Results → Analysis → Recommendation**
ADE's product intent is to increase a user's social media viewership and online presence by automating repetitive social-media work and using AI-assisted analytics to improve future content.
## Mission
Allow the Operator to create a social-media campaign around a Goal and have ADE automate more of the work required to turn source material into a coordinated content plan.
Implement:
**Goal → Campaign → Sources → Content Plan → Drafts → Human Review**
The Operator should increasingly tell ADE **what they are trying to accomplish**, rather than manually creating every individual post.
## 1. Campaigns
Add persistent Campaigns.
Minimum capability:
* campaign name;
* objective;
* associated Goal;
* start/end period where applicable;
* status;
* selected Sources;
* planned content;
* campaign results relationship.
Preserve:
**Goal → Campaign → Source → Content → Publication → Results**
## 2. Campaign Creation
From an existing Goal, allow the Operator to create a Campaign.
Example:
**Goal:** Increase Audience Network by 10
**Campaign:** ADE Awareness Campaign
The Operator should be able to select relevant Sources that ADE may use to produce campaign content.
## 3. Content Plan
ADE should create or assist in creating a simple campaign content plan.
The plan may recommend:
* number of posts;
* content purpose;
* source material;
* intended audience;
* suggested format;
* suggested publication order;
* suggested timing.
Keep this lightweight.
Do not build a complex marketing-management platform.
## 4. Automated Draft Creation
Allow multiple drafts to be generated from the Campaign and selected Sources.
Preserve provenance.
ADE must always be able to answer:
**Which Source contributed to this Draft?**
and:
**Which Campaign and Goal does this Draft support?**
If live AI is available, use the established AI boundary.
If not, retain a clearly identified deterministic/manual test boundary.
## 5. Human Approval Remains Mandatory
Automation must not remove the human decision point.
Generated campaign content must still flow through:
**Draft → Review/Edit → Approve/Reject**
Only approved content may proceed toward publishing.
## 6. Campaign Workspace
Add an operator-facing Campaign view.
The Operator should be able to see:
* campaign objective;
* associated Goal;
* selected Sources;
* planned content;
* drafts;
* approval state;
* publishing state;
* available results.
Keep the experience consistent with the ADE Hub.
## 7. Reduce Manual Work
Validate that ADE can reduce repetitive work.
Instead of requiring:
**Create Source → manually create one post → repeat**
the Operator should be able to:
**Select Goal → Create Campaign → Select Sources → Generate Content Plan/Drafts → Review Decisions**
The Operator remains responsible for judgment.
ADE handles repetitive transformation and organization.
## 8. Analytics Relationship
Prepare Campaigns to consume the existing results/analytics capability.
ADE should be able to aggregate available results at the Campaign level.
Do not add complex analytics if ACI-005 already provides the required primitives.
Reuse the existing capability.
## 9. Validation Scenario
Using clearly identified test data:
Create a Goal such as:
**Increase Audience Network by 10**
Create one Campaign associated with that Goal.
Select at least two Sources.
Have ADE produce a content plan containing multiple pieces of content.
Generate multiple Drafts.
Review them individually.
Approve at least one.
Reject or leave at least one unapproved.
Verify:
* Goal relationship;
* Campaign relationship;
* Source provenance;
* Draft generation;
* human approval;
* publishing eligibility;
* persistence.
## 10. Restart / Regression Validation
Restart ADE.
Verify Campaigns and their relationships persist.
Regression-test:
**Source → Draft → Review → Approval → Queue → Publishing**
and:
**Goal → Content → Results → Analysis → Recommendation**
ACI-006 must not break either proven workflow.
## Non-Goals
Do not implement:
* autonomous publishing;
* real Meta API unless already ready;
* multi-platform expansion;
* enterprise campaign management;
* automatic advertising purchases;
* autonomous business decisions;
* Postiz/Mixpost imports;
* unnecessary new infrastructure.
